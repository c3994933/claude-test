# 人生只有 4000 周

一部 45 秒的竖屏生成式短片（1080×1920，60fps，原创配乐）。画面和声音全部由代码生成，没有使用任何素材。

> 成片 `weeks.mp4` 没有提交进仓库，运行 `./build.sh` 即可在本地重新生成；封面见 `cover.png`。

## 故事

按 80 岁算，一生是 80 年 × 52 周 = 4,160 个星期，画成一张 52 列 × 80 行的格子图。

| 时间 | 段落 | 画面 |
| --- | --- | --- |
| 0–3s | 钩子 | 格子从中心炸开，数字跳到 4,160 ——「你的一生，只有 4,160 个星期」 |
| 3–9s | 规则 | 放大一格，展开成周一到周日；一行是一年，从出生扫到 80 岁 |
| 9–13s | 已经过去的 | 「如果你今年 25 岁」，前 1,300 格依次变灰，标出「你在这里」 |
| 13–26s | 时间去了哪 | 剩下 2,860 格按用途染色：睡觉 ≈ 18 年、工作 ≈ 8 年、刷手机 ≈ 9 年、吃饭通勤家务 ≈ 7 年 ——「真正属于你自己的，大约只剩 12 年」 |
| 26–35s | 父母 | 「如果爸妈今年 55 岁，你每年回家一次，每次 5 天」：25 年里只有 18 格亮起，汇成一块 ——「可能只剩 125 天」 |
| 35–45s | 结尾 | 格子还在一格一格变灰，但剩下的每一格都炸开成彩色 ——「人生只有 4000 周 · 今天，也是其中一格」 |

所有数字都是按片中写明的假设算出来的：每天睡 8 小时、工作到 60 岁（每年 250 个工作日、每天 8 小时）、每天刷手机 4 小时、父母活到 80 岁。

## 制作方式

- `scene.js`：Canvas 2D 渲染引擎，每一帧都是时间 `t` 的纯函数。4,160 个格子各自根据时间计算颜色、亮度和动画。
- `render.js`：用 Playwright 驱动无头 Chromium 并行逐帧渲染；`node render.js cover` 生成封面。
- `music.py`：用 numpy 从零合成 120 BPM 配乐。数字跳动时有计数声，一周七天对应七个上行音，变灰的格子是时钟滴答声；讲到父母时鼓全部撤掉，只留钢琴；结尾格子变彩色时是一阵铃声。

## 生成

```bash
./build.sh
```
