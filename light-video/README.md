# 一束光的旅行

一部 45 秒的竖屏生成式短片（1080×1920，60fps，原创配乐）。画面和声音全部由代码生成，没有使用任何素材。

> 成片 `light.mp4` 体积较大，没有提交进仓库。运行 `./build.sh` 即可在本地重新生成。

## 故事

| 时间 | 段落 | 画面 |
| --- | --- | --- |
| 0–3s | 钩子 | 一束金光打进瞳孔 ——「你此刻看到的阳光，已经旅行了十几万年」，倒带 |
| 3–15s | 困在太阳里 | 太阳核心里诞生一个光子，在等离子体中被撞来撞去；同时显示「此时的地球」从公元前 15 万年走到 2026 年：走出非洲、洞穴壁画、种地、文字、丝绸之路、登月……最后一张卡片是「你，正在刷这条视频」 |
| 15–25s | 冲出太阳 | 光子冲破太阳表面，掠过水星、金星，倒计时 8 分 20 秒飞向地球 |
| 25–35s | 天空为什么是蓝的 | 白光分成七色，蓝光被空气分子撞散（瑞利散射），天空变蓝；穿过云层和树叶的缝隙 |
| 35–41s | 落进眼睛 | 光子落进瞳孔，点亮视网膜上的感光细胞，信号像闪电一样冲进大脑 ——「于是，你看见了光」 |
| 41–45s | 片尾 | 日出下一个抬头的人 ——「一束光的旅行：它走了十几万年，只为落进你的眼里」 |

光子逃出太阳所需的时间，各家估算从数万年到十几万年不等，片中已加注说明。

## 制作方式

- `scene.js`：Canvas 2D 渲染引擎，每一帧都是时间 `t` 的纯函数。程序化生成虹膜、太阳等离子体、随机游走的光子、行星和地球、光谱散射、神经网络、片尾海报，以及辉光、色差、倒带故障等后期效果。
- `render.js`：用 Playwright 驱动无头 Chromium 多页面并行逐帧渲染，并导出时间线 `meta.json`。
- `music.py`：用 numpy 从零合成 120 BPM 配乐。光子每撞一次是一声"滴答"，每张历史卡片对应一个钟音，冲出太阳时进入高潮，散射的蓝光对应一串细碎的铃声。
- `fonts/`：思源黑体、思源宋体、Montserrat（只包含片中用到的字）。

## 生成

```bash
./build.sh
```

依赖：Node + Playwright（Chromium）、Python 3 + numpy、ffmpeg（libx264）。
