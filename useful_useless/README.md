# 有用的无用 · 抖音竖屏短视频

- 成片：`out/有用的无用.mp4`（1080×1920，30fps，68 秒，**带 AI 女声配音**、配乐和音效，配音期间背景音乐会自动压低）
- 字幕：`out/有用的无用.srt`（可导入剪映；想换音色可以把成片配音静音，再用剪映“文本朗读”重新生成）
- 源码：`render.py` 负责画面和音频，`voice.py` 是离线中文 TTS

## 分镜 / 配音稿

| 时间 | 画面 | 配音 |
|---|---|---|
| 0–5s | 大字“有用的 / 无用”弹出，一张卫生纸掉下来 | 今天聊一个，有点味道的哲学问题。 |

| 12–19s | 剪刀沿虚线把四周剪掉，弹出“又省又环保 √节省70%” | 那把它们裁掉，只留中间，岂不是又省又环保？ |
| 19–26s | 手指戳下去，纸破了。红屏、屏幕抖动，大字“翻车了”，音乐突然停 | 结果……你懂的。纸太小，手指一戳就穿。 |

| 42–46s | No.1 杯子：水把中间的“空”装满（老子：当其无，有器之用） | 杯子能装水，靠的是中间的“空”。 |

## 发布建议

- 标题：擦屁股为什么不能只用中间那一小块？｜有用的无用
- 话题：#有用的无用 #冷知识 #庄子 #生活哲学 #科普
- 换配音：成片里的 AI 配音是离线模型合成的，音色比较普通。想要更自然的声音，可以在剪映里把原声音量调低，导入 srt，用“文本朗读”重新生成。

## 重新渲染

```bash
pip install pillow numpy scipy pypinyin ai-edge-litert tensorflow-cpu
pip download zhtts==0.0.1 --no-deps -d zhtts_dl && cd zhtts_dl && python3 -m zipfile -e zhtts-0.0.1-py3-none-any.whl pkg && cd ..
python3 voice.py patch zhtts_dl/pkg/zhtts/asset   # 把模型里的 Flex 算子换成 TFLite 内置算子（只需做一次）
VOICE_ASSETS=zhtts_dl/pkg/zhtts/asset python3 render.py
```

不设 `VOICE_ASSETS` 就只渲染配乐和音效。`python3 render.py preview 10 20` 只导出预览帧。

配音模型来自 zhtts（FastSpeech2 + MB-MelGAN），训练数据是标贝中文女声数据集。这个数据集的授权只允许非商业用途。如果账号要接商单或开通变现，建议换成剪映的配音。
