# 有用的无用 · 横屏短视频

- 成片：`out/有用的无用_横屏.mp4`（1920×1080，30fps，68 秒，**只带音效**，没有配音和配乐，BGM 后期自己加）
- 字幕：`out/有用的无用.srt`（画面里已经烧录了字幕，这个文件只是备用）
- 源码：`render.py`（`python3 render.py` 重新渲染；`python3 render.py audio` 只重做音效、不重画画面；`python3 render.py preview 10 20` 只导出预览帧）

## 音效清单

转场呼呼声、文字弹出、纸巾落地、条形图上涨、摸鱼警示哔哔、剪刀咔嚓、四边飞走、“又省又环保”成功和弦、手指下落、撕裂 + 轰、红色警报、庄子原文打字声、倒水、车开过、一格格掉电、低电量提示、日程块飞入落位、叮。

## 版式

左边放插图，右边放关键词，字幕在底部。顶部是栏目名和进度条。

## 配 BGM（剪映）

1. 导入 `有用的无用_横屏.mp4`，把《千年之后》拖到音频轨。
2. 建议把副歌的起点对在 **26 秒**（“原来周围那一圈不是没用”开始揭晓的地方），情绪最顺。也可以对在 35 秒庄子出场的地方。
3. 歌比视频长的话，在 68 秒处剪断，最后 2 秒做淡出。
4. 视频自带音效。如果觉得音效抢了歌，把视频原声音量调到 30–50%。
