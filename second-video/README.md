# 1 秒钟，能发生什么？

一部 45 秒的竖屏生成式短片（1080×1920，60fps，原创配乐）。画面和声音全部由代码生成，没有使用任何素材。

> 成片 `second.mp4` 没有提交进仓库，运行 `./build.sh` 即可在本地重新生成；封面见 `cover.png`。

## 故事

秒表走满 1 秒后定格，然后把这 1 秒拆开看：

| 场景 | 这 1 秒里 | 依据 |
| --- | --- | --- |
| 光 | 绕地球跑了 7.5 圈 | 光速约 30 万公里/秒，地球周长约 4 万公里 |
| 地球 | 带着你在太空里飞了约 30 公里 | 公转速度约 29.8 公里/秒；赤道自转约 465 米/秒 |
| 闪电 | 全世界落下约 44 道闪电 | 全球平均约 44 次/秒 |
| 出生 | 约 4 个婴儿出生，约 2 个人离开 | 每年约 1.3 亿出生、约 6 千万死亡 |
| 太阳 | 约 400 万吨物质变成光和热 | 太阳每秒质量损失约 400 万吨 |
| 心脏 | 跳了约 1 下 | 静息心率约每分钟 60–100 次 |
| 细胞 | 约 380 万个细胞被更新 | 人体每天约更新 3300 亿个细胞 |

反转：「等等——你已经看了 34 秒了」。计时器开始走真实时间，婴儿数、闪电数、光绕地球的圈数、更新的细胞数都按真实秒数实时计算。结尾：「每一秒，都有奇迹发生 · 别浪费你的下一秒」。

## 制作方式

- `scene.js`：Canvas 2D 渲染引擎，每一帧都是时间 `t` 的纯函数。程序化绘制秒表、地球、太阳、闪电、婴儿、心脏、心电图和由细胞粒子组成的人形；反转段的计数器按视频的真实播放时间计算。
- `render.js`：用 Playwright 驱动无头 Chromium 并行逐帧渲染；`node render.js cover` 生成封面。
- `music.py`：用 numpy 从零合成 120 BPM 配乐。秒针的嘀嗒声贯穿全片；每个场景有自己的音效：盘旋的琶音、闪电的噼啪声、八音盒、心跳；反转处唱片急停，接着是真实的秒针声。

## 生成

```bash
./build.sh
```
