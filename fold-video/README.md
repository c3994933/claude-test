# 一张纸对折 42 次，能碰到月亮？

一部 45 秒的竖屏生成式短片（1080×1920，60fps，原创配乐）。画面和声音全部由代码生成，没有使用任何素材。

> 成片 `fold.mp4` 没有提交进仓库，运行 `./build.sh` 即可在本地重新生成；封面见 `cover.png`。

## 故事

一张纸厚约 0.1 毫米，每对折一次厚度翻倍：厚度 = 0.1 毫米 × 2ⁿ。镜头跟着纸堆一路往上拉，跨越 30 多个数量级。

| 对折次数 | 厚度 | 参照物 |
| --- | --- | --- |
| 10 | 10.2 厘米 | 桌上的杯子 |
| 14 | 1.64 米 | 和你一样高 |
| 17 | 13 米 | 4 层楼 |
| 20 | 105 米 | 30 多层大楼 |
| 23 | 839 米 | 超过迪拜塔（828 米） |
| 27 | 13.4 公里 | 超过珠峰（8,849 米） |
| 30 | 107 公里 | 越过太空边界（100 公里） |
| 32 | 429 公里 | 超过空间站（约 400 公里） |
| 42 | 约 44 万公里 | 碰到月亮（约 38.4 万公里） |
| 51 | 约 2.25 亿公里 | 超过太阳（约 1.5 亿公里） |
| 103 | 约 1,072 亿光年 | 比可观测宇宙（约 930 亿光年）还大 |

然后是反转：「但现实中，人类最多只把纸对折过 13 次」。最后落到指数的力量：1.01³⁶⁵ ≈ 37.8，0.99³⁶⁵ ≈ 0.03。

## 制作方式

- `scene.js`：Canvas 2D 渲染引擎，每一帧都是时间 `t` 的纯函数。用以米为单位的世界坐标和对数缩放的镜头，按真实尺寸摆放桌子、人、房子、大楼、迪拜塔、珠峰、云层、太空边界、空间站、地球、月球、太阳、银河系和可观测宇宙。
- `render.js`：用 Playwright 驱动无头 Chromium 并行逐帧渲染；`node render.js cover` 生成封面。
- `music.py`：用 numpy 从零合成 120 BPM 配乐。每次对折是一声纸响加一个上行音，越过每个参照物都有一次重击，碰到月亮时进入高潮；反转处急刹车，只剩八音盒。

## 生成

```bash
./build.sh
```
