# 选择 · Choice

一部 48 秒的生成式短片（1920×1080，30fps，含原创配乐）。所有画面与声音均由代码实时生成，没有使用任何素材。

**成片：** [`choice.mp4`](choice.mp4)

## 故事

| 时间 | 段落 | 画面 |
| --- | --- | --- |
| 0–7s | 起点 | 星尘中，一点光被点亮 ——「每一刻，都是一次选择」 |
| 7–13s | 岔路 | 光走到第一个分岔口，两条虚线交替闪烁，犹豫不决 ——「向左，还是向右」 |
| 13–19s | 抉择 | 光选择了向上，金色的路被点亮，另一条路黯淡成蓝色 ——「选择一条路，便告别了另一条」 |
| 19–30s | 未选之路 | 镜头拉远，所有未被选择的路重新亮起、不断分叉，长成一棵蓝紫色的可能性之树 ——「未曾走过的路，也在某处，静静发光」 |
| 30–36s | 汇聚 | 整棵树化作近六千粒光尘，飞越画面，汇聚成金色的「选择」 |
| 36–48s | 你 | 「CHOICE」——「你走过的每一步，都在成为你」 |

金色是你走过的路，蓝紫色是你没有走的路；最后，它们一起组成了「选择」。

## 制作方式

- `scene.js` — Canvas 2D 场景。每一帧都是时间 `t` 的纯函数（种子随机数），可任意顺序渲染。分叉树、光点轨迹、镜头、粒子汇聚、字幕都在这里。
- `render.js` — 用 Playwright 驱动无头 Chromium 逐帧渲染为 PNG（多页面并行），并导出时间线 `meta.json`。
- `music.py` — 用 numpy 从零合成配乐（D 大调氛围铺底、钟声、拨弦、上升的闪光音云、卷积混响），所有音符按 `meta.json` 的时间点与画面同步：犹豫时左右声道交替、每个分岔一个五声音阶上行音、粒子落定时的细碎铃音。
- `index.html` + `fonts/` — 思源宋体（Noto Serif SC，仅包含片中用到的字）与 Cormorant Garamond。

在浏览器里打开 `index.html`（需通过本地 HTTP 服务）可以实时预览动画。

## 重新生成

```bash
./build.sh
```

依赖：Node + Playwright（Chromium）、Python 3 + numpy、ffmpeg（libx264）。
