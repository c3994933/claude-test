# 选择 · CHOICE

一部 45 秒的生成式短片（1920×1080，30fps，120 BPM 原创配乐）。画面和声音全部由代码生成，没有使用任何素材。

> 成片约 150 MB，超出 GitHub 单文件上限，没有提交进仓库。运行 `./build.sh` 即可在本地重新生成 `choice.mp4`。

## 分镜

| 时间 | 段落 | 画面 |
| --- | --- | --- |
| 0–4s | 钩子 | 彩色光爆炸，数字飞速跳到 **35,000** ——「据说，人每天要做 35,000 个选择」 |
| 4–10s | 一天的选择 | 卡点快切：早起 / 再睡五分钟、咖啡 / 茶……时钟从 07:00 走到 23:59；最后停在「留下 / 离开」，犹豫、故障闪烁、黑场 |
| 10–14s | 转折 | 「但有些选择」→「会改变一切」，霓虹世界淡入 |
| 14–20s | 岔路 | 第一人称飞驰在霓虹公路上，前方一分为二：左边是落日，右边是极光 ——「向左？」「向右？」「你会怎么选？」，时间静止 |
| 20–28s | 抉择（Drop） | 一个急转向左，整片天空被落日染红；之后每两拍一个岔路，没走的路上浮现「另一座城市」「另一份梦想」「另一段相遇」「另一个你」 |
| 28–34s | 平行宇宙 | 镜头升空俯瞰：走过的金色道路两旁，是无数条五彩的未选之路 ——「每一条没走的路，都藏着另一个你」 |
| 34–36s | 汇聚 | 整张路网化作光流旋转着涌向中心 |
| 36–45s | 标题 | 金色「选择 / CHOICE」重击登场 ——「没有标准答案，只有你的答案」 |

## 制作方式

- `scene.js` — Canvas 2D 渲染引擎：每一帧都是时间 `t` 的纯函数。包含 3D 透视飞行镜头（偏航、俯仰、侧倾）、程序化路网、天空与山脉、粒子、动态文字，以及辉光、色差、故障、闪白、震屏等后期效果。
- `render.js` — 用 Playwright 驱动无头 Chromium 多页面并行逐帧渲染，并导出时间线 `meta.json`。
- `music.py` — 用 numpy 从零合成 120 BPM 配乐（vi–IV–I–V 和弦进行）：底鼓、拍手、踩镲、侧链压缩的 Supersaw 和弦、贝斯、琶音、钢琴、上升音效、冲击音效、倒放镲。每一个重音都对准画面上的切点、岔路和标题。
- `index.html` + `fonts/` — 思源黑体、思源宋体、Montserrat（只包含片中用到的字）。

## 生成

```bash
./build.sh
```

依赖：Node + Playwright（Chromium）、Python 3 + numpy、ffmpeg（libx264）。
