# 《周五晚上，为什么比周六快乐》

一支 110 秒的短片：`friday_night.mp4`（1280×720，30fps，带合成配乐）。
重新生成：`python3 make_video.py`（需要 Pillow、numpy、ffmpeg 和 Noto CJK 字体：`apt install fonts-noto-cjk`）。
检查单帧：`python3 make_video.py preview 16 42` 会导出第 16、42 秒的画面。

## 想表达的核心思想

> 我们真正热爱的，也许不是周末本身，而是「还有周末」。

周五晚上，周末一分钟都还没有用掉，**所有的可能性同时存在**：睡懒觉、看电影、去海边、见朋友……
到了周六，每选择一件事，其余的可能就消失了，可能性**坍缩**成唯一的现实。
同时，终点开始变得可见，「周一」的影子一点点逼近，快乐被倒计时稀释。

所以周五晚上的快乐，主要来自**期待**，而期待是一种「提前支取的快乐」。
（心理学上有相近的发现：Nawijn 等人 2010 年对荷兰度假者的研究显示，度假者在出发前的幸福感就已高于不度假的人；而假期结束后，这种差别很快消失。）

但影片不想停在“期待比现实好”这种略带虚无的结论上，于是有一个转折：

> 可能性，总是比现实更甜；但只有现实，才能被真正活过。

最后给出三条“把周六过成周五晚上”的方法，并以一句祝福收尾：
**愿你的每一天，都有一个在等你的周末。**

## 视觉设计思路

| 时间 | 段落 | 画面 | 设计意图 |
|---|---|---|---|
| 0–7.5s | 提问 | 黑底白字 | 用一个人人都有体会的小问题把人拉进来 |
| 7.5–21s | 周五 18:00 → 19:10 | 深蓝紫夜空、星星、亮着暖灯的城市；12 个“可能性光点”逐个亮起 | 光点 = 周末的所有可能，此刻它们全都属于你 |
| 21–34s | 周六 11:05 → 11:40 | 明亮但发白的白天；光点纷纷熄灭，只剩“睡到自然醒”移到中央 | **可能性坍缩**：选择一个，就失去其余 |
| 34–46s | 周六 20:30 → 21:30 | 灰蓝色傍晚，窗灯渐熄；右侧“周一”的黑影推进；配乐出现钟表滴答 | **倒计时**：终点可见，快乐被稀释 |
| 46–67.5s | 快乐曲线 | 一条示意曲线：峰值在周五晚（暖色=期待），之后转冷色并在周日晚下坠 | 把感受变成结构：快乐 = 期待 + 体验 |
| 68–84s | 思考 | 全黑中一颗呼吸的光点 | 留白，让观众自己想；给出转折 |
| 84.5–98s | 方法 | 三行字依次出现 | 从“为什么”落到“怎么办” |
| 98–110s | 结尾 | 回到周五夜的星空配色 | 首尾呼应：把周五晚上的感觉带回每一天 |

贯穿全片的小道具是左上角的**时钟和「周末余额」进度条**。两者用同一个时间计算（周末按周五 18:00 到周一 0:00 共 54 小时算），所以始终对得上：周五 18:00 是 100%，周六上午约 68%，周六晚上约 50%。它像手机电量一样，让“时间被消耗”变得看得见。

## 声音

配乐全部由程序用正弦波合成：周五和结尾用温暖的大调和弦（Cmaj7–Am7–Fmaj7–G），
周六夜到思考段落切换到偏忧郁的进行（Am–F–Em–G），周六夜加入每秒一次的钟表滴答，暗示倒计时。

## 可以继续加强的方向

- 加中文配音（把字幕作为旁白稿即可）
- 用实拍或插画替换几何图形，例如周五地铁上的人群、周六中午拉着窗帘的卧室
- 做成竖屏 9:16 版本发短视频平台
