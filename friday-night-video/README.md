# 《周五晚上，为什么比周六快乐》

一支 108 秒的短片：`friday_night.mp4`（1280×720，30fps，带合成配乐）。
重新生成：`python3 make_video.py`（需要 Pillow、numpy、ffmpeg 和文泉驿正黑字体）。

## 想表达的核心思想

> 我们真正热爱的，也许不是周末本身，而是「还有周末」。

周五晚上，周末一分钟都还没用掉，**所有的可能性同时存在**：睡懒觉、看电影、去海边、见朋友……
到了周六，每选择一件事，其余的可能就消失了，可能性**坍缩**成唯一的现实。
同时，终点开始变得可见，「周一」的影子一点点逼近，快乐被倒计时稀释。

所以周五晚上的快乐，主要来自**期待**，而期待是一种「提前支取的快乐」。
（心理学上有相近的发现：Nawijn 等人 2010 年对荷兰度假者的研究显示，度假带来的幸福感提升，最明显的部分出现在出发之前的期待阶段。）

但影片不想停在“期待比现实好”这种略带虚无的结论上，于是有一个转折：

> 可能性，总是比现实更甜；但只有现实，才能被真正活过。

最后给出三条“把周六过成周五晚上”的方法，并以一句祝福收尾：
**愿你的每一天，都有一个在等你的周末。**

## 视觉设计思路

| 时间 | 段落 | 画面 | 设计意图 |
|---|---|---|---|
| 0–7s | 提问 | 黑底白字 | 用一个人人都有体会的小问题把人拉进来 |
| 7–19s | 周五 18:47 | 深蓝紫夜空、星星、亮着暖灯的城市；12 个“可能性光点”逐个亮起 | 光点 = 周末的所有可能，此刻它们全都属于你 |
| 19–33s | 周六 11:20 | 明亮但发白的白天；光点纷纷熄灭，只剩“睡到自然醒”移到中央 | **可能性坍缩**：选择一个，就失去其余 |
| 33–45s | 周六 21:05 | 灰蓝色傍晚，窗灯渐熄；右侧“周一”的黑影推进；配乐出现钟表滴答 | **倒计时**：终点可见，快乐被稀释 |
| 45–66s | 快乐曲线 | 一条示意曲线：峰值在周五晚（暖色=期待），之后转冷色并在周日晚下坠 | 把感受变成结构：快乐 = 期待 + 体验 |
| 66–82s | 思考 | 全黑中一颗呼吸的光点 | 留白，让观众自己想；给出转折 |
| 82–96s | 方法 | 三行字依次出现 | 从“为什么”落到“怎么办” |
| 96–108s | 结尾 | 回到周五夜的星空配色 | 首尾呼应：把周五晚上的感觉带回每一天 |

贯穿全片的小道具是左上角的**「周末余额」进度条**：100% → 72% → 45%，像手机电量一样，让“时间被消耗”变得可见。

## 声音

配乐全部由程序用正弦波合成：周五和结尾用温暖的大调和弦（Cmaj7–Am7–Fmaj7–G），
周六夜到思考段落切换到偏忧郁的进行（Am–F–Em–G），周六夜加入每秒一次的钟表滴答，暗示倒计时。
